# 国会議員 年齢データ可視化システム

衆議院公式ウェブサイトおよび参議院公式ウェブサイトを**唯一の情報源**として、日本の国会議員のデータ（生年月（日））を収集し、Webブラウザ上で当月1日時点の満年齢を動的に計算・可視化するシステムです。

## 構成ファイル
- `scraper.py`: 衆議院・参議院の公式ウェブサイトから基本情報および生年月（日）をスクレイピングし、`data.json` を生成するスクリプトです。**年齢そのものはデータとして保持せず、生年月（日）のみを保存します。**
- `requirements.txt`: 実行に必要なPython依存パッケージです。
- `index.html`: サマリー、会派別データ、全議員のソート・絞り込みテーブルを備えたWebページです。
- `app.js`: `data.json` を読み込み、クライアント側で「当月1日時点の満年齢」および各種統計値（平均・中央値・最高年齢）を動的に計算・描画します。
- `style.css`: 客観的かつ中立的なデザインのCSSスタイルシートです。
- `README.md`: 本ドキュメントです。

## 動作要件
- Python 3.8以上
- モダンブラウザ (Chrome, Edge, Firefox, Safari等)

## セットアップと実行手順

1. **Pythonパッケージのインストール**
```bash
pip install -r requirements.txt
```

2. **データ収集スクリプトの実行**

- **テスト実行（衆議院・参議院 各5名ずつ迅速に取得）:**
```bash
python scraper.py --test
# または短縮形
python scraper.py -t
```
> サーバ側への負荷軽減と動作確認のため、各議院5名（計10名）のみを高速に取得します。

- **全件取得（全議員 約700名超）:**
```bash
python scraper.py
```
> サーバーへの負荷軽減（robots.txtおよびマナー遵守）のため、リクエスト間に1秒以上のスリープ（`time.sleep(1.0)`）を設けています。そのため、全議員の取得には約15分〜20分を要します。

- **件数指定実行:**
```bash
python scraper.py --limit 10
# または短縮形
python scraper.py -l 10
```

- **指定IDのデータのみ更新（個別更新）:**
```bash
# 単一のIDを指定して更新
python scraper.py -i 001

# 複数のIDをカンマ区切りで指定して更新
python scraper.py -i 001,006,010
```
> 指定した議員のみのプロフィールページを直接再取得して最新のパース結果（生年月日、出身地、出身校、学部名等）で `data.json` / `data.js` を高速に更新します。

- **全件データの復元（テスト実行後に全件データへ戻す場合）:**
```bash
python scraper.py --restore
# または短縮形
python scraper.py -r
```
> テスト実行（`--test`）時に既存の全件データがある場合、自動的に `data_full.json` / `data_full.js` へ退避されます。`--restore` を実行することで、再スクレイピング不要で即座に全件データを復元できます。

3. **Webページの閲覧**
以下のいずれかの方法で閲覧できます。

- **方法A：直接ブラウザで開く（推奨・最も簡単）**
  エクスプローラー等から `index.html` をダブルクリックしてブラウザで開くだけで、データが正常に表示されます（Webサーバーの起動は不要です）。

- **方法B：ローカルWebサーバー経由で開く**
```bash
python -m http.server 8000
```
  ブラウザで `http://localhost:8000` にアクセスしてください。

## 主な機能
- **動的年齢計算**: 保存された「生年月（日）」データを元に、フロントエンド（JavaScript）側で**当年1月1日時点**の満年齢を動的に計算します。
- **サマリー**: 衆議院・参議院ごとの平均年齢・中央値・最高年齢と、日本国民（全体・有権者）との比較が可能です。
- **会派別データ**: 各政党・会派ごとの平均年齢・中央値・最高年齢・所属人数を一覧表示します。
- **出身地別データ（棒グラフ）**: 都道府県別・外国・不明の議員数を横棒グラフで視覚化します。議院別（全体/衆議院/参議院）、並び順（議員数順/地域順）、表示対象（出身者がいる地域のみ/上位20地域/全国47都道府県＋外国・不明）の切り替えに対応しています。
- **個別リスト**: 全議員のID、氏名、議院、会派、当選回数、生年月日、年齢、出身地、出身校、学部名を一覧表示します。「議院」「会派」「出身校」による複合絞り込み、および「ID」「当選回数」「年齢」「出身地」「出身校」列での昇順・降順ソート、公式プロフィールページへの直接リンクが可能です。

## 情報源
- **衆議院議員データ**: 衆議院公式ウェブサイト（https://www.shugiin.go.jp/）
- **参議院議員データ**: 参議院公式ウェブサイト（https://www.sangiin.go.jp/）
- **日本国民年齢データ（参考情報）**: 総務省統計局「人口推計」等の公表データに基づく
